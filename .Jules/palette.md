## 2026-06-27 - Consolidated ARIA labels for Links
**Learning:** Screen readers stagger reading for links with multiple child elements. Consolidated aria-label on parent and aria-hidden on children prevents this.
**Action:** Applied consolidated aria-label to Backlinks link.
## 2026-06-27 - Focus Visible with CSS Variables
**Learning:** Custom Astro Starlight components may lack focus rings for keyboard navigation. Used var(--sl-color-accent) for outline.
**Action:** Added :focus-visible outline to Backlinks link.
