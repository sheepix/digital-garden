## 2026-07-03 - [Consolidated Aria Labels and Explicit Focus Styles for Backlinks]
**Learning:** For lists of links that contain multiple inline elements (like title and category `span`s), screen readers may stagger or double-read the content if the parent `a` tag doesn't have a single coherent label. Furthermore, default `:focus` states can be inconsistent or insufficient for visibility, specifically when overriding theme styles, making `:focus-visible` with a clear outline necessary.
**Action:** Always apply a consolidated `aria-label` on the parent interactive element (`a` or `button`) and add `aria-hidden="true"` to the inner decorative or layout children to prevent staggered readouts. Also, explicitly define `.link:focus-visible` using the theme's existing accent color CSS variables to guarantee high-contrast keyboard navigation cues.
