## 2024-05-31 - Fix Staggered Link Readouts and Landmark Context in Astro Components
**Learning:** For components containing complex links (multiple `span` elements for layout, like a category and title side-by-side), screen readers often read each nested element disjointedly, resulting in a staggered and confusing experience. Additionally, structural UI landmarks like `<aside>` are not implicitly announced with context unless specifically labelled.
**Action:** Always apply a consolidated `aria-label` to the parent `<a>` element containing the full intent, and explicitly set `aria-hidden="true"` on the inner stylized children (`<span>`) to prevent disjointed reading. For layout sections like `<aside>`, explicitly connect them to their internal headings via `aria-labelledby` and a corresponding `id` to provide descriptive context to screen reader users.
