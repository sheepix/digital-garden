## 2026-07-06 - Consolidate Backlink Screen Reader Output
**Learning:** In Astro components mapping links with multiple block/inline elements (like category and title spans in `<a class="backlink-link">`), screen readers can stutter or read contents as disjointed elements unless consolidated. Using an `aria-label` on the parent `<a href...>` while explicitly setting `aria-hidden="true"` on the inner descriptive children creates a seamless auditory experience without modifying the visual styling. In addition, properly labeling complementary structural components (e.g. `<aside aria-labelledby="heading-id">`) ensures proper screen reader navigation between page regions.
**Action:** Consistently use the 'consolidated label + hidden children' pattern for any composite link elements or complex buttons within this design system.
